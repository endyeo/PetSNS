# PetSNS 시작 안내

반려동물 추억, 약속, 게시글, 모임·약속 채팅을 체험하는 Flutter 앱입니다. 모바일을 우선으로 만들고 웹·Android를 지원합니다.

## 실행

`C:\Projects\PetSNS`에서 실행합니다.

```powershell
flutter pub get
flutter run -d chrome --web-port 8080
```

기록을 유지하려면 같은 호스트·8080 포트를 사용하세요. 이미 서버가 실행 중인 포트에는 중복 실행하지 않습니다. 연결된 Android 기기는 `flutter run -d <device-id>`로 실행합니다.

## 지금 가능한 것

로그인 화면에서 테스트 이용을 선택하면 가입 없이 체험할 수 있습니다. 새로고침해도 기록·세션이 유지되고, 테스트 이용은 기록을 초기화하지 않습니다. 데이터는 기기에 `petsns.v1` JSON으로 저장됩니다.

한 기기·한 활성 앱에서 사용하는 데모입니다. 서버, 실제 이메일 인증, 비밀번호 찾기, 여러 기기 동기화는 없습니다. 운영용 인증으로 사용할 수 없습니다. 저장소 삭제·앱 제거 시 기록이 사라질 수 있고, 예시 사진·지도는 인터넷 연결이 필요합니다.

## 알아두면 좋은 규칙

- 약속 정원은 자동 참여하는 작성자를 포함한 보호자 2~50명입니다. 시작 6시간 전에 참여가 마감되며 마감 정각에는 참여할 수 없습니다. 새 약속은 시작까지 6시간 넘게 남아야 합니다.
- 약속 채팅은 약속 다음 날까지 이용합니다. 예: 10월 1일 약속 → 10월 3일 00:00 한국 시간 종료. 모임방에는 약속 날짜에 따른 자동 종료가 없습니다.
- 나가면 접근이 차단되고, 재참여하면 새 참여 이후의 대화·사진만 보입니다. 약속방 나가기는 해당 약속 참여, 모임방 나가기는 해당 모임 가입만 취소합니다.
- 추억·하루 글·Day 0는 가족별로 관리합니다. 사진을 삭제해도 하루 글은 남습니다. 선택한 사진은 장당 3MB 이하입니다.

## 새 채팅에서 이어가기

프로젝트를 연결하고 원하는 화면·동작을 설명하면 됩니다. AI는 루트 `AGENTS.md`에서 시작해 관련 코드와 테스트를 확인합니다. 화면은 주로 `lib/main.dart`, 저장·규칙은 `lib/store.dart`, 테스트는 `test/`에 있습니다.

코드를 바꿀 때는 `flutter analyze`와 관련 `flutter test`로 확인합니다. 이번 문서 정리는 앱 테스트·빌드를 새로 실행한 작업이 아닙니다.
